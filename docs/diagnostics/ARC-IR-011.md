# ARC-IR-011 — Invalid dimension

A dimension value could not be parsed. In a size axis, a bare value must be a number with a unit (px/pt/mm), a percentage, or one of the size keywords 'fill', 'fit_content', and 'aspect(W:H)'.

**Typical fix:** Use a number with a unit (e.g. '40pt', '210mm', '1080px'), a percentage, or a size keyword ('fill', 'fit_content', 'aspect(3:4)').
