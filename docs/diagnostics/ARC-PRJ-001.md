# ARC-PRJ-001 — No project found

No project.yaml was found in the current directory or any parent, and no valid project directory was given (--project on the CLI, the 'project' argument over MCP), so there is no project to act on.

**Typical fix:** Run inside a project directory, pass the project directory explicitly (--project <dir> on the CLI, 'project' over MCP), or create one (arcavex project new / arcavex_project_create).
