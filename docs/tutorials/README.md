# Tutorials

Task-focused walkthroughs. Each one is self-contained and drives the real engine; for the reference
material behind them see [template-schema.md](../template-schema.md) and [cli.md](../cli.md).

| Tutorial | You will learn |
|---|---|
| [Building a template from scratch](building-a-template.md) | Scaffold, nodes, constraints, anchors, sizes, stacks, and fit policies — from `template new` to a rendered card. |
| [A bilingual template](bilingual-template.md) | Locales, digit policies, RTL, font stacks, data overlays, and per-format patches, using the reference poster as the worked example. |
| [Using and writing extensions](extensions.md) | When you need an extension, the scaffold → validate → test → add → enable loop, and the trust model. |

New to Arcavex? Do the [quick start](../quick-start.md) first — it renders the shipped examples in
about ten minutes.
