# CLI command reference

Generated by `scripts/generate_skill_reference.py` from the running CLI's help model. Use `arcavex COMMAND --help` for arguments, defaults, and examples.

| Command | Purpose | Options |
|---|---|---|
| `arcavex asset add` | Ingest an image into the content-addressed store and report its reference (§4.7). | `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex asset annotate` | Write sidecar annotations (facing/focal_point/tags) onto an ingested asset (§4.7). | `--set`, `--annotations`, `--json`, `--no-color`, `--quiet` |
| `arcavex batch` | Render every matched project's formats × locales in parallel jobs. | `--jobs/-j`, `--dpi`, `--json`, `--no-color`, `--quiet` |
| `arcavex data import` | Merge a YAML data document into the current project's data (overlay semantics, §3.7). | `--locale/-l`, `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex data set` | Set a single value in the current project's data, then revalidate (spec §3.7). | `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex desktop handshake` | Report engine identity, compatibility versions, paths, capabilities, and health. | `--json`, `--no-color` |
| `arcavex diff` | Diff two recorded runs: per-output pixels/perceptual plus provenance changes. | `--json`, `--no-color`, `--quiet` |
| `arcavex doctor` | Check the environment (Python, Skia, ICU, fonts, temp dir) and engine version. | `--json`, `--no-color`, `--quiet` |
| `arcavex editor apply` | Execute one semantic transaction; a refusal reports conflicts or diagnostics. | `--json`, `--no-color`, `--quiet` |
| `arcavex editor history` | Show the undo/redo timeline and whether an external edit branched it. | `--project/-p`, `--json`, `--no-color`, `--quiet` |
| `arcavex editor redo` | Re-apply the oldest undone history entry. | `--project/-p`, `--json`, `--no-color`, `--quiet` |
| `arcavex editor undo` | Restore the project state before its newest applied history entry. | `--project/-p`, `--json`, `--no-color`, `--quiet` |
| `arcavex effects inspect` | Show one effect's category and full parameter schema. | `--json`, `--no-color`, `--quiet` |
| `arcavex effects list` | List the registered effects, their category, and each param's type/default/range. | `--json`, `--no-color`, `--quiet` |
| `arcavex explain` | Explain a diagnostic code: what it means and the typical fix. | `--json`, `--no-color`, `--quiet` |
| `arcavex ext add` | Validate and add a local extension to the Arcavex home, recorded disabled. | `--json`, `--no-color`, `--quiet` |
| `arcavex ext disable` | Disable an added extension (deregistered on the next run). | `--json`, `--no-color`, `--quiet` |
| `arcavex ext enable` | Enable an added extension (its components register on the next run). | `--json`, `--no-color`, `--quiet` |
| `arcavex ext list` | List every added local extension, its enabled state, and its components. | `--json`, `--no-color`, `--quiet` |
| `arcavex ext scaffold` | Scaffold a new, immediately-valid extension directory of the given kind. | `--name`, `--json`, `--no-color`, `--quiet` |
| `arcavex ext test` | Run the extension's golden fixtures in a crash-contained subprocess. | `--json`, `--no-color`, `--quiet` |
| `arcavex ext validate` | Validate an extension's manifest, compatibility, imports, determinism, and schemas. | `--json`, `--no-color`, `--quiet` |
| `arcavex font add` | Install a font into the Arcavex home and report the family name templates must use. | `--license`, `--json`, `--no-color`, `--quiet` |
| `arcavex font list` | List every font family the engine can resolve, marking bundled vs installed. | `--json`, `--no-color`, `--quiet` |
| `arcavex font remove` | Remove an installed font family; a family bundled with the engine is refused. | `--json`, `--no-color`, `--quiet` |
| `arcavex layout inspect` | Report resolved geometry: per-node bounds, anchors, overflow, and sibling overlaps. | `--project`, `--data/-d`, `--format/-f`, `--locale/-l`, `--json`, `--no-color`, `--quiet` |
| `arcavex list-runs` | List recorded runs (project's, or with --path a direct-mode outputs dir), newest first. | `--project`, `--path`, `--json`, `--no-color`, `--quiet` |
| `arcavex mcp serve` | Start the MCP authoring server over stdio (spec §6.2). |  |
| `arcavex mcp tools` | List the MCP tool catalog (names, descriptions, and input/output schemas). | `--json`, `--no-color` |
| `arcavex preview` | Preview a template to a stable path (with --watch, keep re-rendering), or the project. | `--data/-d`, `--format/-f`, `--locale/-l`, `--style`, `--project`, `--watch`, `--dpi`, `--debug`, `--json`, `--no-color`, `--quiet` |
| `arcavex project clone` | Clone the current (or --project) project into a new directory, reset to draft. | `--name`, `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex project new` | Scaffold a renderable project pinning a template version. | `--template/-t`, `--name`, `--style`, `--format/-f`, `--locale/-l`, `--json`, `--no-color`, `--quiet` |
| `arcavex project set-status` | Set the current project's lifecycle status. | `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex project upgrade` | Preview a template-version upgrade; with --yes, update the pin. | `--to`, `--yes`, `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex render` | Render a template to an image or PDF, or (no template) the current project's runs. | `--data/-d`, `--format/-f`, `--locale/-l`, `--style`, `--output/-o`, `--project`, `--record`, `--dpi`, `--quality`, `--lossless`, `--debug`, `--json`, `--no-color`, `--quiet` |
| `arcavex rerun` | Reproduce a recorded run into a new run directory (byte-identical on match). | `--json`, `--no-color`, `--quiet` |
| `arcavex skill install` | Install the bundled design skill so an AI assistant knows how to drive Arcavex. | `--target/-t`, `--path`, `--force`, `--project`, `--list`, `--json`, `--no-color`, `--quiet` |
| `arcavex status` | Show the current project's manifest and recorded-run count. | `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex style inspect` | Show a style pack's palettes, fonts, effect presets, and role defaults. | `--json`, `--no-color`, `--quiet` |
| `arcavex style list` | List the installed style packs (spec §3.7). | `--json`, `--no-color`, `--quiet` |
| `arcavex template check` | Validate a template without data (schema + structure + preview_data). | `--format/-f`, `--locale/-l`, `--style`, `--json`, `--no-color`, `--quiet` |
| `arcavex template detach` | Copy the project's library template into the project (disables version upgrades). | `--project`, `--json`, `--no-color`, `--quiet` |
| `arcavex template inspect` | Report a template's variables, formats, node IDs, functions, and example data. | `--resolved`, `--format/-f`, `--locale/-l`, `--json`, `--no-color`, `--quiet` |
| `arcavex template new` | Scaffold a minimal renderable template directory. | `--json`, `--no-color`, `--quiet` |
| `arcavex template patch` | Apply path-addressed set/remove/insert ops to a template on disk (comment-preserving). | `--set`, `--value`, `--remove`, `--insert-before`, `--insert-after`, `--node`, `--ops-file`, `--base-sha256`, `--json`, `--no-color`, `--quiet` |
| `arcavex template publish` | Publish a template directory into the library as an immutable version. | `--name`, `--version`, `--default`, `--json`, `--no-color`, `--quiet` |
| `arcavex template split` | Convert a one-file template into a split directory losslessly. | `--json`, `--no-color`, `--quiet` |
| `arcavex validate` | Validate a template, or (with no template) the current project, without rendering. | `--data/-d`, `--format/-f`, `--locale/-l`, `--style`, `--project`, `--json`, `--no-color`, `--quiet` |
